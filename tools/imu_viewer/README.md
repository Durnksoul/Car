# 串口姿态网页

## 在线站点

已发布：[IMU660RC 串口姿态](https://imu660rc-serial-viewer.cosmic-smile-8441.chatgpt.site)。当前仅站点所有者账号可访问。使用独立 Chrome 或 Edge 打开，登录后选择电脑连接的开发板串口，波特率 115200。在线版不需要运行下面的本地启动程序。

在线发布源码位于 `../../sites/imu660rc-viewer/`，站点身份保存在该目录的 `.openai/hosting.json`。

## 本地启动

双击 `StartViewer.cmd` 启动，程序优先使用独立 **Chrome**，未安装时使用独立 **Edge** 打开 http://127.0.0.1:8765 。启动窗口需要保持打开，关闭窗口会停止本地网页服务。如果服务已运行，重复双击会复用服务并打开浏览器。

1. 开发板运行项目当前固件，用 USB 串口连接电脑。
2. **关闭 VS Code 的 ESP-IDF Monitor 和其他串口助手**，释放端口。
3. 网页保持波特率 **115200**，点击「连接串口」，选择开发板对应的端口。
4. 上电时保持传感器静止 3 秒，等待固件记录 Yaw 零点。页面收到角度后，三个数值和模型会随模块转动。

当前固件的串口格式已经匹配，无须为网页修改固件：

```text
roll=1.23,pitch=-2.34,yaw=45.67
```

网页采用浏览器 Web Serial API，只读取数据，不发送设备命令。所有文件均在本地，无外部脚本或联网依赖。串口权限需要在浏览器的端口选择窗口中手动授权。

「查看演示」使用模拟数据，页面明确标注演示模式，方便在未连接硬件时查看效果。真实连接时演示按钮不可用；数据停止时显示最后一帧并提示「数据暂停」，不会假装仍在接收。

模型坐标轴按模块丝印显示：新 +X 沿原模型的 +Y 方向，新 +Y 沿原模型的 -X 方向，+Z 保持原方向。在这组坐标中，Roll 绕 +X 轴、Pitch 绕 +Y 轴、Yaw 绕 +Z 轴；模型前方箭头沿模块 +X。页面保留串口原始的三个角度，通过局部坐标映射绘制坐标轴，板体和姿态旋转保持对齐。

Yaw 是相对启动朝向的转角；跨越 ±180° 时直接更新方向，模型不把边界跳变当作反向旋转一整圈。实际车体安装方向需自行对应。

## 启动与排查

- VS Code 终端中也可运行 `python tools/imu_viewer/serve.py`，随后访问上述地址。
- 端口 8765 已被使用时，运行 `python tools/imu_viewer/serve.py --port 8766`。
- 无法打开串口：确认已关闭 Monitor/串口助手；在网页断开后再烧录或使用 Monitor。
- 显示「已连接 · 等待数据」：展开「串口消息」查看初始化信息。如果只有日志没有角度，检查 IMU 供电、SPI 和 INT2 接线。
- 提示浏览器不支持：将地址复制到 Chrome 或 Edge 的普通窗口；直接双击 HTML 文件不作为推荐启动方式。
- 点击后没有设备选择窗口：页面会显示「等待选择串口」，8 秒后提供提示，30 秒后结束本次等待并恢复按钮。点击页底「用独立浏览器打开」，在新窗口中连接。浏览器原生选择窗口无法由网页强制关闭；若之前的选择还没结束，请先关闭选择窗口或刷新页面再重试。
- 选完设备后显示打开失败或超时：这是打开串口阶段的问题，请关闭 Monitor/串口助手、核对 USB 连接后重试。打开阶段超时为 10 秒；若设备晚于超时才打开，页面会释放该端口，避免留下占用。

## 验证

运行 `node tools/imu_viewer/test.mjs` 检查串口分包、日志过滤、数值解析、模型轴向，以及连接、主动断开、拔除设备和重复连接的资源释放。

运行 `python tools/imu_viewer/test_server.py` 检查独立浏览器入口。测试使用模拟浏览器启动，不会打开真实串口。JavaScript 测试同时覆盖选择超时、打开超时、过期结果、取消选择和端口打开失败。

浏览器串口接口参考：[Chrome 官方 Web Serial 文档](https://developer.chrome.com/docs/capabilities/serial)。本地网页及模拟数据验证不等同于传感器硬件实测。
